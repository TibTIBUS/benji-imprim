# Benji Imprim

Landing page premium de Benji Imprim, entreprise française spécialisée dans
l'impression 3D sur mesure pour les professionnels.

## Développement

```bash
npm install
npm run dev
```

## Déploiement Netlify

Le dépôt est prêt pour le déploiement continu sur Netlify :

- commande de build : `npm run build`
- dossier publié : `.next`
- version de Node.js : 20

Le formulaire de devis est déclaré comme formulaire Netlify sous le nom
`demande-devis`.
